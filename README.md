Futbol News Bot

📌 Descripción

Este proyecto es un agente automático que recopila y publica diariamente las 3 noticias más virales del fútbol mundial. El objetivo es automatizar la búsqueda, procesamiento y difusión de contenido deportivo.

📂 Estructura del proyecto

NoticiasFutbol/
│
├── data/             → Archivos de datos intermedios (JSON, TXT)
├── docs/             → Documentación del proyecto (.gitkeep incluido)
├── media/            → Imágenes, audios y videos relacionados (.gitkeep incluido)
├── scripts/          → Código Python (ej. noticias_virales.py)
├── requirements.txt  → Dependencias del proyecto
└── URL Repositorio GitHub.txt → Enlace directo al repositorio

⚙️ Instalación

Clonar el repositorio:

git clone https://github.com/cacsadtic1-ctrl/futbol-news-bot.git

Crear y activar entorno virtual:

python -m venv .venv
.venv\Scripts\activate

Instalar dependencias:

pip install -r requirements.txt

🚀 Uso

Ejecutar el script principal para obtener las noticias:

python scripts/noticias_virales.py

📌 Objetivos

Automatizar la recopilación de noticias virales de fútbol.

Publicar contenido diario sin intervención manual.

Mantener una estructura clara y organizada del proyecto.

📖 Notas

Las carpetas docs/ y media/ incluyen archivos .gitkeep para asegurar su visibilidad en GitHub.

Se recomienda mantener documentación en docs/ y recursos multimedia en media/.
